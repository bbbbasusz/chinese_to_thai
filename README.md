## ภาษาไทย 🇹🇭

เครื่องมือแปลงภาษาจีนเป็นอักษรไทย รองรับอักษรจีนตัวย่อและตัวเต็ม พินอิน (Pinyin) และจู้อิน (Zhuyin / 注音符號) โดยแปลงเสียงภาษาจีนเป็นอักษรไทยพร้อมเครื่องหมายวรรณยุกต์ตามกฎการถอดเสียงที่กำหนด

**คุณสมบัติหลัก**

* รองรับอักษรจีนตัวย่อและตัวเต็ม
* ป้อนข้อความได้ทั้งอักษรจีน พินอิน และจู้อิน
* แปลงข้อความโดยอัตโนมัติ
* รองรับการแสดงวรรณยุกต์ภาษาไทย
* เลือกการอ่านสำหรับอักษรที่มีหลายเสียงได้
* มีแป้นพิมพ์จู้อินและเครื่องหมายกำกับเสียง
* คัดลอกผลลัพธ์ได้ในคลิกเดียว

## 中文 🇨🇳

这是一款将汉语读音转换为泰文字母的在线工具，支持简体中文、繁体中文、汉语拼音（Pinyin）和注音符号（Zhuyin）。工具会根据设定的转写规则，将输入内容转换为泰文，并处理相应的声调标记。

**主要功能**

* 支持简体中文和繁体中文
* 支持汉字、汉语拼音和注音符号输入
* 自动转换为泰文字母
* 根据规则处理泰语声调符号
* 支持多音字读音选择
* 提供注音符号虚拟键盘和声调符号键盘
* 一键复制转换结果

## 한국어 🇰🇷

중국어 발음을 태국 문자로 변환하는 웹 도구입니다. 간체자와 번체자, 한어병음(Pinyin), 주음부호(Zhuyin)를 입력할 수 있으며, 설정된 전사 규칙에 따라 태국 문자와 성조 표기로 변환합니다.

**주요 기능**

* 중국어 간체자·번체자 지원
* 한자·한어병음·주음부호 입력 지원
* 실시간 자동 변환
* 태국어 성조 표기 규칙 적용
* 다중 발음 한자의 발음 선택
* 주음부호 및 성조 기호 가상 키보드
* 변환 결과 원클릭 복사

## English 🇬🇧

An online tool for converting Chinese pronunciation into Thai script. It supports Simplified and Traditional Chinese characters, Hanyu Pinyin, and Zhuyin (Bopomofo), converting input into Thai script according to the implemented transliteration rules, including Thai tone-mark handling.

**Key Features**

* Supports Simplified and Traditional Chinese
* Accepts Chinese characters, Hanyu Pinyin, and Zhuyin
* Automatic real-time conversion
* Thai tone-mark handling based on the implemented rules
* Pronunciation selection for polyphonic Chinese characters
* Virtual Zhuyin and diacritic keyboards
* One-click copying of converted text
